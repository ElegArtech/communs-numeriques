Note méthodologique

Ces matrices sont générées directement à partir des métadonnées du fichier CODE.md. Elles reflètent fidèlement le codage réalisé sur les 13 entretiens. L’intensité suit l’échelle : ✓ (faible), ✓✓ (modéré), ✓✓✓ (fort), [-] (code absent).
