# Signaler un problème de sécurité ou de confidentialité

Pour une faille, une fuite de données, un document privé publié par erreur
ou un problème sensible de droits, écrire à
[consulting@alexandre-berge.fr](mailto:consulting@alexandre-berge.fr).

Indiquer l'URL ou le fichier concerné, une description du problème et, si
possible, des étapes de reproduction sans données confidentielles. Ne pas
recopier des entretiens ou des informations personnelles dans le message ;
décrire où ils apparaissent suffit pour un premier signalement.

Ne pas ouvrir d'issue publique pour ces sujets. Les corrections ordinaires
de texte et les liens cassés peuvent utiliser les modèles d'issues.

La version maintenue est celle de `main` et du site publié. Il n'existe pas
de programme de prime ni d'engagement de délai de réponse. Le mainteneur
évalue le signalement, prépare la correction et convient avec la personne
qui l'a signalé des informations pouvant être rendues publiques.

En cas de document privé commité, sa suppression dans un nouveau commit
ne l'efface pas de l'historique. Le mainteneur doit aussi évaluer les copies,
l'historique et les artefacts concernés avant de clore le signalement.
